# MILESTONE M1 — Corpus ingest and MCP server

Exit criterion: “a bare agent with only `corpus.*` answers ‘which papers cite
p17’ from facts and ‘which paper introduced X’ with a passage id” → PASS.

Evidence:

- `docs/evidence/m1-cites-p17.json`: the agent calls incoming `citations`, sees
  `total: 0`, and reports that no indexed paper cites `p17`.
- `docs/evidence/m1-introduced-vpp.json`: the agent searches for Video
  Prediction Policy, reads `p4-abstract`, and answers `p4` with that passage ID.
- `packages/corpus/tests`: GROBID TEI parsing, reference resolution, stable
  identifiers, structural facts, BM25 search, and all nine MCP tools.

The ingest produced 37 papers, 2,683 passages, 2,384 references, outlines,
facts, and a BM25S index. DBLP IDs are verified; unmatched input would receive
a content-derived `local:paper/` identifier as approved in the M1 amendment.

Decisions: ADR 0003 pins the CPU GROBID service and preserves Docling as the
per-document fallback.

Deviations: `p17` has no incoming citation in the supplied corpus, so the
correct fact-backed answer is an empty result rather than a list of papers.

and SHACL validation; implement SPARQL checking and query-derived coverage plans.
